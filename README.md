# 自适应网格的守恒多层扩散算子

合成热像计算窗包含一个未细化工位和一组温度不同的细格。 数据为本地合成。

- `data/capture.json` 保存采集原始内容。records 是交换记录，tensors 字段分开描述名称、类型、形状和值。整数索引从零开始，未指定闭合的区间均为左闭右开。
- `data/capacity.json` 保存制造端的容量、规模或分片条件。大尺寸是接口需考虑的使用规模。工作区计入新分配的解包、转换、归约、版本暂存及交接缓冲。调用方已有只读输入和已消费的输出不计入工作区，额外物化副本计入。

## 交换约定

几何盒 `[x0,x1,y0,y1]` 描述轴对齐叶格，空间整数单位。体积为盒面积，热容密度为一。配方中正导热系数 `k` 按叶格携带。共享面的热系数为面长度除以两侧半宽到面距离分别除以各自 k 后之和。当外边界定温时，只有本侧半宽参与距离计算；绝热边不交换热量。正温差使热量从高温侧流向低温侧。
显式步只用当前可见温度。例中细格采用 `ratio` 个等长子步，跨级面上的粗格温度在该粗步内保持起始值，粗格在本级步末得到对应各时段积累的等量反号热量。同级离散在所属级步上更新。稳定条件是每格单次更新区间面系数和乘本级步长不大于格体积，在粗细同步处也要按对应粗步检查。修订只能从给定格点按二等分细化或恢复四格父格；旧格均匀温度投到原区域，新温度是新格的体积加权温度。回传目标是初始各活动叶格温度。

## 读取资料

使用 Python 3.11。首次创建本地环境时安装锁定依赖。只读查看显示原始字段和张量尺寸。

```sh
python -m pip install -r requirements.txt
python caseio.py data/capture.json
python -m unittest discover -s tests -v
```

现有检查核对采集格式和所附数据的结构。
