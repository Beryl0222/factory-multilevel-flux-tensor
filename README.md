# 自适应网格的守恒多层扩散算子

合成热像计算窗包含一个未细化工位和一组温度不同的细格。 数据为本地合成。

- `data/capture.json` 保存采集原始内容。records 是交换记录，tensors 字段分开描述名称、类型、形状和值。整数索引从零开始，未指定闭合的区间均为左闭右开。
- `data/capacity.json` 保存制造端的容量、规模或分片条件。大尺寸是接口需考虑的使用规模。工作区计入新分配的解包、转换、归约、版本暂存及交接缓冲。调用方已有只读输入和已消费的输出不计入工作区，额外物化副本计入。

## 交换约定

几何盒 `[x0,x1,y0,y1]` 描述轴对齐叶格，空间整数单位。体积为盒面积，热容密度为一。配方中正导热系数 `k` 按叶格携带。共享面的热系数为面长度除以两侧半宽到面距离分别除以各自 k 后之和。当外边界定温时，只有本侧半宽参与距离计算；绝热边不交换热量。正温差使热量从高温侧流向低温侧。
显式步使用各自时间段起点可见的温度。第零级使用 `dt`，每细化一级，其步长为上一级的 `1/ratio`。跨级面取同一交换时段内较粗叶格本级步开始的温度，较粗叶格在本级步末收到该步内累积的等量反向热量。两叶格相差多级时仍按实际步长和共有的面片计算。同级叶格在共同步开始时互读温度。稳定条件是每格单次更新区间面系数和乘本级步长不大于格体积，在粗细同步处也按对应粗步检查。
网格修订只在外步开始前发生。给定父格可沿两轴对半细化，四块同级叶格也可恢复其父格。旧格的均匀温度分布在原区域，新温度按新格体积加权。外步无法接受时，调用方继续使用上一个已交付的网格与温度。`nested_sequence` 按顺序给出候选修订和时间步配置，每项从最近已交付的格网和温度开始。`nested_upstream` 针对该序列的零基下标及输出网格，梯度的目标域为该步开始前的活动叶格。

## 读取资料

使用 Python 3.11。首次创建本地环境时安装锁定依赖。只读查看显示原始字段和张量尺寸。

```sh
python -m pip install -r requirements.txt
python caseio.py data/capture.json
python -m unittest discover -s tests -v
```

现有检查核对采集格式和所附数据的结构。
